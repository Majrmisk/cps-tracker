# CPS Tracker

A web app for tracking occupancy at the University Computer Centre (CPS) of Masaryk University.

---

## Live Website

Deployed on Streamlit Cloud: [cps-tracker.streamlit.app](https://cps-tracker.streamlit.app/)

---

## Technologies Used

| Purpose          | Package / Service                     |
|------------------|---------------------------------------|
| UI / Hosting     | **Streamlit**                         |
| Database         | **MotherDuck (DuckDB)**               |
| Automation       | **GitHub Actions** + **cron-job.org** |
